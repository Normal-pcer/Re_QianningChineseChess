# 千宁中国象棋（抽卡版）

一款融合了中国象棋规则与 RPG 卡牌元素的回合制双人对战网页游戏。在传统象棋走法的基础上，每个棋子都拥有生命值、攻击力、防御力等属性，玩家每回合可以抽取一张技能卡牌来改变战局。

## 快速开始

### 环境要求

- [Node.js](https://nodejs.org/)（用于 TypeScript 编译）
- [Python 3](https://www.python.org/) + Flask（用于运行本地服务器）

### 安装运行

```bash
# 1. 安装依赖
npm install
pip install flask

# 2. 编译 TypeScript
npx tsc

# 3. 启动服务器
python server.py

# 4. 浏览器访问
# http://localhost:1919
```

进入首页后点击「多人游戏」即可开始双人对战。

## 玩法介绍

### 基本规则

游戏使用标准中国象棋棋盘（9 列 × 10 行），双方各有 16 枚棋子：

| 棋子 | 红方名称 | 黑方名称 | 数量 |
|------|---------|---------|------|
| 将/帅 | 帅 | 将 | 1 |
| 士/仕 | 仕 | 士 | 2 |
| 象/相 | 相 | 象 | 2 |
| 马 | 马 | 馬 | 2 |
| 车 | 車 | 車 | 2 |
| 炮 | 炮 | 砲 | 2 |
| 兵/卒 | 兵 | 卒 | 5 |

双方轮流行动，红方先行。与标准象棋不同，**吃子不再是"必杀"**——你需要通过多轮攻击削减对方棋子的生命值。

### 棋子属性

每个棋子拥有以下属性：

| 属性 | 说明 |
|------|------|
| 生命值（HP） | 归零时棋子被移出棋盘 |
| 攻击力（ATK） | 基础伤害值 |
| 防御力（DEF） | 伤害减免：实际伤害 = 伤害量 × 2^(-防御/1000) |
| 暴击率 | 攻击时的暴击概率，1 表示必定暴击 |
| 暴击伤害倍率 | 暴击时伤害的加成倍率，0 表示暴击伤害等于普通伤害 |
| 重量 | 影响击退抵抗能力 |
| 伤害类型 | 近战低/中/高、远程、魔法，影响受击位移行为 |

所有棋子在游戏开局时拥有「初始之护」效果（提升 11000 点防御力，持续 3 回合），用于防止早期打马。

### 行动流程

每回合玩家可以：
1. **移动**：选中己方棋子，点击蓝色高亮的合法目标格
2. **攻击**：选中己方棋子，点击红色高亮的敌方棋子进行攻击
3. **抽卡**：点击右侧「抽卡」按钮，消耗回合抽取一张技能卡
4. **使用卡牌**：点击手牌中的卡牌并选择目标

---

### 伤害系统

伤害计算分两步：先计算基础伤害，再应用**伤害浮动**（±2% 随机偏移），最后根据防御力减免。

伤害公式：

```
实际伤害 = 伤害量 × 2^(-防御力/1000)
```

其中魔法伤害会使防御力减半计算。

不同伤害类型有不同的受击位移效果：

| 类型 | 说明 | 位移效果 |
|------|------|---------|
| 近战低 | 近距离轻击 | 无位移 |
| 近战中 | 近距离中击 | 攻击方贴近目标 |
| 近战高 | 近距离重击 | 目标被击退 |
| 远程 | 远程攻击 | 无位移 |
| 魔法 | 魔法攻击 | 防御减半（公式中防御力/2） |

击退系统受目标重量影响：重量越高，抵抗击退的概率越大。

---

### 卡牌系统

每方手牌上限为 6 张。卡池共 14 种卡牌，按权重随机抽取：

| 卡牌 | 权重 | 效果 |
|------|------|------|
| 高射炮 | 1.0 | 炮移动时忽略路径中的炮架要求 |
| 一马平川 | 1.0 | 马移动时忽略蹩脚限制 |
| 力量药水 | 1.0 | 提升攻击力 |
| 虚弱药水 | 1.0 | 降低敌方攻击力 |
| 治疗药水 | 1.0 | 回复 600 点生命值 |
| 再生药水 | 1.0 | 每回合回复生命值上限一定比例的生命值 |
| 戴钟之鼎 | 1.0 | 大幅增加棋子重量 |
| 决意流搏 | 1.0 | 提升暴击率 |
| 威震四方 | 1.0 | 炮的范围攻击 |
| 剧毒药水 | 1.0 | 每回合造成百分比生命上限 + 固定值的魔法伤害 |
| 力量药水（加强） | 0.5 | 攻击力提升 25%，持续 2 回合 |
| 力量药水（延长） | 0.5 | 攻击力提升 15%，持续 5 回合 |
| 忍俊不禁 | 0.5 | 麻痹敌方棋子，不能主动移动和攻击 |
| 剧毒药水（加强） | 0.5 | 更高比例的持续魔法伤害 |

### 状态效果

棋子可同时拥有多个状态效果（增益/减益），效果具有以下特性：
- **等级机制**：同效果叠加时提升等级（以罗马数字显示 I、II、III…）
- **时效机制**：效果有持续回合数，到期自动清除
- **每回合触发**：部分效果在每个回合结束时自动生效（再生、毒药等）
- **启用/禁用**：效果可被临时禁用而不删除

效果模板包括「力量」（攻击力提升）、「虚弱」（攻击力降低）、「生命恢复」（每回合回复生命值）、「剧毒」（每回合造成魔法伤害）。效果通过「属性修饰器」系统修改棋子的各项属性，详见下方。

## 核心系统

### 走法与攻击

使用**策略模式**解耦棋子行为。每种棋子通过 `PieceMovingStrategy` 和 `PieceAttackingStrategy` 接口定义其走法和攻击规则。标准走法实现在 `defaultMovingBehaviors.ts` 中，完全遵循传统中国象棋规则：

- **将/帅**：九宫格内一步（上下左右）
- **士/仕**：九宫格内斜走一步
- **象/相**：田字对角，有塞眼限制，不可过河
- **马**：日字走法，有蹩脚限制
- **車**：直线任意距离，无子阻挡
- **炮**：移动同車，攻击需翻山（隔一子）
- **兵/卒**：未过河只能前进，过河可左右

特殊卡牌可以临时替换走法策略（如「一马平川」去除蹩脚限制），效果结束后恢复原策略。

### 伤害与位移

攻击命中后的位移行为由 `PieceMovingStrategy` 的 `damageBehavior` 定义：

- **准移动**（QuasiMove）：攻击方自动移至目标位置
- **击退**（Repel）：目标沿攻击方向后退

位移效果受伤害类型影响，且击退成功率与目标重量成反比。

### 抽卡与卡池

抽卡使用确定性随机数（基于 Mersenne Twister），权重越低的卡牌越稀有（0.5 为稀有卡，1.0 为普通卡）。每次抽卡消耗当前回合并切换到对方回合。

### 属性修饰器

`attributeProvider` 提供灵活的多层属性修改机制。每个属性由「属性提供器」（`AttributeProvider`）管理，基于「乘区」运作：

- 每个棋子拥有多个属性乘区
- 每个乘区有一个基础值和一个修改器列表
- 修改器使用**加法合并**（数值累加，`PlusMerge`）或**覆盖合并**（对象替换，`OverrideMerge`）
- 修改器支持到期自动清除

这使得卡牌和状态效果可以通过增删修改器来精确操控棋子属性，并在效果过期后自动还原。

### 存档与回退

完整的游戏状态持久化系统：

- **存档**（Save）：捕获所有棋子、玩家手牌、回合数、触发器和调度器的完整状态
- **读档**（Load）：从 localStorage 中加载存档并完全恢复游戏状态
- **悔棋**（Recall）：撤销最近一步操作，回退到上一步存档
- **序列化框架**：自研的基于装饰器的序列化系统，支持循环引用、自定义构造参数和反序列化后处理

存档通过 `serialize.ts` 框架将对象图转换为 JSON 字符串。`TypeRegistry` 使用装饰器注册类，确保反序列化时能正确重建类型信息。

### 回合调度

`scheduler` 系统允许将某个操作延迟到未来的特定回合执行。主要用于状态效果在上级效果过期后的"降级"处理（如高级力量药水过期后自动应用普通的次级力量药水）。

### 随机数系统

基于 Mersenne Twister（MT19937）实现的确定性随机数生成器。`fixedRandom(seed, context)` 接受种子和上下文字符串，确保在相同种子和上下文下产生相同的随机数序列。这保证了从同一存档恢复后，后续的抽卡和战斗随机结果完全一致。

## 构建与运行

```bash
# 安装 TypeScript（可选，推荐全局安装）
npm install -g typescript

# 编译项目
npm install
tsc

# 或者使用 VS Code：Ctrl+Shift+B 运行默认构建任务（tsc && python pre.py）

# 启动本地服务器（端口 1919）
python server.py

# 在浏览器中打开
# http://localhost:1919        → 首页
# http://localhost:1919/multiplayer.html  → 直接进入游戏
```

VS Code 调试配置（`.vscode/launch.json`）支持在 Edge 或 Chrome 中启动调试，编译作为前置任务自动执行。

## 调试与隐藏指令

游戏内置了调试功能：

| 指令/操作 | 效果 |
|-----------|------|
| `Alt + K` | 启用调试模式 |
| 输入 `/recall` | 悔棋 |
| 输入 `/store` | 手动存档 |
| 输入 `/load` | 读档 |

此外，棋盘上还有监听 `input` 事件的隐藏输入区域，支持以上文本指令。
